  ## Step 2: Details

  Project Details

  > Solana TUI Explorer is a keyboard-driven terminal interface for Solana developers who want to inspect chain state without context switching to a browser explorer. It combines wallet,
  > token, transaction, and network inspection into a single CLI workflow so developers can investigate accounts, analyze transaction failures, and monitor validator/network activity
  > directly from the terminal.
  >
  > The project reduces friction in day-to-day Solana debugging by surfacing account deserialization, transaction stack tracing, compute usage, and local validator interactions in a
  > readable TUI. It is designed for developers building with Anchor, SPL tokens, and Solana RPC, with a strong focus on fast inspection and debugging during active development.
  >
  > The current codebase includes a CLI package, a secure proxy server for AI-assisted debugging, and multiple TUI panels for wallet, token, and dashboard views. The goal of the grant is to
  > continue improving the explorer experience, expand debug coverage, and make Solana diagnostics more accessible for terminal-first builders.
